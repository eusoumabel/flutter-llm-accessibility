# Análise

Este diretório armazena os artefatos analíticos do estudo, incluindo métricas, figuras, tabelas e notebooks usados para interpretar os resultados do benchmark.

## Conteúdo planejado

- metrics/: arquivos de matriz de confusão e métricas agregadas
- figures/: gráficos e visualizações
- tables/: tabelas de resumo e comparações
- notebooks/: análise exploratória de dados e notebooks de relatório
