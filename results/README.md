# Resultados

Este diretório armazena os resultados dos experimentos em duas etapas distintas:

- raw/: respostas brutas da API e metadados da requisição
- normalized/: saídas estruturadas prontas para análise

Os dados brutos devem permanecer imutáveis após a recepção do provedor do modelo. A camada normalizada é gerada a partir desses arquivos brutos e pode ser transformada sem alterar a evidência original.
