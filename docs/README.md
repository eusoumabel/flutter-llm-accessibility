# Documentação

Este diretório contém a documentação metodológica e operacional do projeto de pesquisa.

## Conteúdo

- methodology.md: desenho da pesquisa, perguntas, hipóteses e protocolo
- dataset_protocol.md: como as amostras entram no dataset e como são validadas
- adding_samples.md: passo a passo para criar samples, metadata JSON e mutações
- annotation_guidelines.md: critérios de classificação para cada violação de acessibilidade
- experiment_protocol.md: checklist operacional para execuções de modelos e controles de execução
- execution_guide.md: ordem dos scripts, preparação do ambiente e comandos de execução
- analysis_protocol.md: estratégia de matching, métricas e procedimentos de agregação
- glossary.md: dicionário dos termos científicos e técnicos do projeto
- research_log.md: espaço cronológico para decisões, problemas e descobertas
- decisions.md: decisões metodológicas formalizadas em formato ADR simplificado
- threats_to_validity.md: limitações conhecidas e considerações de viés
